# Avrupa Araştırmaları Derneği — geçici web sayfası

Derneğin kurumsal web sitesi açılana kadar kullanılacak, harici bağımlılığı olmayan statik karşılama sayfası.

## İçerik

- index.html — sayfa içeriği ve bağlantılar
- styles.css — duyarlı sayfa tasarımı
- assets/logo-transparent.png — sayfada kullanılan, dış zemini şeffaf amblem
- assets/favicon.png — sekme simgesi için kare kırpılmış tam amblem
- assets/logo.jpg — orijinal kaynak görsel

## Yayınlama

Sayfa herhangi bir derleme adımı gerektirmez. Dosyaları statik site barındırma hizmetine yüklemek yeterlidir. GitHub Pages kullanırken depo ayarlarından Pages bölümünü açıp main dalının kök dizinini yayın kaynağı olarak seçin. Özel alan adını barındırma hizmetindeki ilgili alana ekleyin.
